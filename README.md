# The Event Planners AI — website

Three static pages for the TikTok developer app requirements.

- `index.html` — home / what the service does
- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `style.css`, `logo.png` — shared assets

## Publishing on GitHub Pages

1. Go to https://github.com/new — create a repo named `eventplannersai`, set it **Public**.
2. On the empty repo page click **uploading an existing file**.
3. Drag in all five files (`index.html`, `terms.html`, `privacy.html`, `style.css`, `logo.png`). Commit.
4. Go to **Settings → Pages**. Under "Build and deployment", set Source = `Deploy from a branch`, Branch = `main`, folder = `/ (root)`. Save.
5. Wait 1–2 minutes. Your URLs will be:

   - Website:  `https://YOURUSERNAME.github.io/eventplannersai/`
   - Terms:    `https://YOURUSERNAME.github.io/eventplannersai/terms.html`
   - Privacy:  `https://YOURUSERNAME.github.io/eventplannersai/privacy.html`

Replace `YOURUSERNAME` with your GitHub username. Confirm all three load in a browser
before pasting them into TikTok — the reviewers do check that they resolve.
